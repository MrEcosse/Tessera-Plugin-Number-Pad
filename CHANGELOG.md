# Changelog

## 0.1.1
- README: the use case (a set of four wall-panel tiles for conference rooms, sports bars and the like), and an LG webOS
  example.

## 0.1.0
- First version: a tile with the keys 0 to 9 and an optional Clear and Enter. Each digit can be sent as soon as it is
  tapped, or the digits gather above the keys and go together on Enter. The action is one text with `{digit}` and
  `{code}` in it. The number is forgotten after an idle time. From one cell up to 4x4.
